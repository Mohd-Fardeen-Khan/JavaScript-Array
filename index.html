Array Methods

 

1. Push Method: Add to end

in push method we can add the value or some elements can be added in the End for eg. let cars=["Audi","BMW","Maruti","Lamborgini"]; console.log(cars); Output: (4) ['Audi', 'BMW', 'Maruti', 'Lamborgini'] cars.push("Toyota"); console.log(cars); Output: (5) ['Audi', 'BMW', 'Maruti', 'Lamborgini', 'Toyota'] cars.push("Ferrari"); console.log(cars); Output: (6) ['Audi', 'BMW', 'Maruti', 'Lamborgini', 'Toyota', 'Ferrari']


2. Pop Method: Remove from end & returns it

in pop method we can remove the value or some elements can be removed in the End or the value(index) which we can be tell in the time for running for eg. let cars=["Audi","BMW","Maruti","Lamborgini"]; console.log(cars); Output: (4) ['Audi', 'BMW', 'Maruti', 'Lamborgini'] cars.pop(); console.log(cars); Output: (3) ['Audi', 'BMW', 'Maruti'] cars.pop(); console.log(cars); Output: (2) ['Audi', 'BMW']


3. Unshift Method:Add to start

in Unshift method we can add the value or some elements can be added in the start of the element which we can be tell in the time for running for eg. let fruits=["Banana","Apple"]; console.log(fruits); Output: (2) ['Banana', 'Apple'] fruits.unshift("Mango"); console.log(fruits); Output: (3) ['Mango', 'Banana', 'Apple']


4. Shift Method:Delete from start

in shift method we can Delete or return the value or some elements can be delete in the start of the element which we can be tell in the time for running for eg. let fruits=["Banana","Apple"]; console.log(fruits); Output: (2) ['Banana', 'Apple'] fruits.shift(); console.log(fruits); Output: ['Apple']

15. map()

Takes an array , Changes each element, Returns a new array, Original array stays same let nums = [1, 2, 3, 4]; let result = nums.map(function(n) { return n * n; }); console.log(result); // [1, 4, 9, 16] Output: (4) [1, 4, 9, 16]


16. filter()

Checks a condition, Keeps only elements that are true, Returns a new array let nums = [1, 2, 3, 4, 5, 6]; let even = nums.filter(n => n % 2 === 0); console.log(even); // [2, 4, 6] Output: (3) [2, 4, 6]


17. reduce()

Combines all elements into one value, Example: sum, total, max, count let nums = [10, 20, 30]; let sum = nums.reduce((total, n) => { return total + n; }, 0); console.log(sum); // 60 Output: 60
